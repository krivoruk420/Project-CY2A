# Project CY2A

**Рабочее название автомобиля:** Hirochi Cuirassier (предварительное)  
**Статус:** Pre-Alpha / Planning

Project CY2A — самостоятельный lore-friendly автомобиль для BeamNG.drive, вдохновлённый Mitsubishi Lancer X (2007–2017). Цель — спроектировать оригинальный автомобиль марки Hirochi с собственной геометрией, физикой JBeam и системой повреждений. Mitsubishi Lancer X служит техническим ориентиром; оригинальные игровые ресурсы и чужие материалы без разрешения в проект не включаются.

На текущем этапе репозиторий содержит документацию и инструменты подготовки. Здесь пока нет 3D-модели, игровых файлов или рабочего JBeam. Первый прототип будет создан только после получения правомерных исходных материалов и проверки исходных технических данных.

## Цели

- Создать оригинальный кузов с пропорциями и компоновкой, близкими к выбранному серийному ориентиру.
- Построить настраиваемую физику BeamNG с правдоподобной подвеской и деформацией.
- Поддерживать раздельно исходники, документацию и файлы, устанавливаемые в игру.
- Проверять происхождение и право использования каждого стороннего материала.

## Развитие

План включает подготовку инфраструктуры, сбор легально используемых исходных данных, создание первого прототипа, настройку агрегатов и кузова, проверку базовой версии 1.5, расширение линейки 1.6/1.8/2.0 и позднее спортивную ветку по мотивам Evolution X. Этапы и критерии выхода описаны в [ROADMAP.md](docs/ROADMAP.md).

## Настройка окружения

Для работы с документацией достаточно Git и редактора Markdown. Для будущих исходников потребуются Blender и инструменты импорта/экспорта, выбранные после изучения актуальной версии BeamNG.drive. Для упаковки требуется Python 3.10+; скрипт использует только стандартную библиотеку:

```powershell
python tools/package_mod.py
```

До появления игровых файлов команда завершится с объяснением, что собирать пока нечего. Установка и рабочий процесс описаны в [DEVELOPMENT_GUIDE.md](docs/DEVELOPMENT_GUIDE.md).

## Структура

```text
docs/       спецификация, дорожная карта, данные автомобиля и политика материалов
references/ чертежи, размеры, фото и технические источники с учётом прав
source/     исходники Blender и текстуры проекта
game/       дерево игровых файлов BeamNG.drive
tools/      локальные инструменты проекта
tests/      проверки структуры и упаковщика
dist/       локальные ZIP-сборки (не коммитятся)
```

Правила внесения исходных и сторонних материалов см. в [политике материалов](docs/THIRD_PARTY_MATERIALS.md).
